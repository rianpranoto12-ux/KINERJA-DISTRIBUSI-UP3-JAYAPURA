DASHBOARD KINERJA DISTRIBUSI PLN UP3 JAYAPURA

1. Ekstrak seluruh isi ZIP ke satu folder.
2. Buka index.html di Chrome, Edge, atau Firefox. Pertahankan folder assets
   di sebelah index.html.
3. Pilih periode, unit, dan indikator. Pilih grafik Garis, Batang, atau Titik
   untuk tren bulanan dan perbandingan ULP.
4. Gunakan Data kerja dan tombol Input / edit atau Tambah rincian untuk
   memasukkan data. Pada panel Evaluasi & rencana aksi, klik Edit analisa &
   evaluasi untuk memperbarui kedua catatan sesuai periode, unit, dan
   indikator yang dipilih. Angka awal pada mode simulasi adalah contoh.
5. Untuk memindahkan data kerja dari dashboard online, klik Ekspor data kerja
   di dashboard online, lalu klik Impor data kerja pada dashboard lokal dan
   pilih file JSON hasil ekspor. Data kerja tersimpan di browser. Gunakan
   ekspor JSON untuk cadangan. Jika browser membatasi penyimpanan untuk file
   lokal, jalankan folder ini lewat server lokal, misalnya dengan perintah
   python -m http.server 8000, lalu buka http://localhost:8000.
6. Peta menggunakan OpenStreetMap. Koneksi internet diperlukan untuk memuat
   peta dasar. Penanda ULP dan fitur lainnya dapat ditampilkan secara lokal.
